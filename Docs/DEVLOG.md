### 수정: 내 캐릭터가 자기 몸에 가려진 부분을 하늘색 실루엣으로 칠하는 문제
- 사용자가 플레이어 모델을 직접 교체한 뒤 발생. 새 모델은 SkinnedMeshRenderer 2개에 서브메시가 6개, 8개
- 원인: `XRaySilhouette`는 렌더러에 Mark/Silhouette 머티리얼을 덧붙이는데, 머티리얼 수가 서브메시보다 많으면 덧붙인 머티리얼은 **마지막 서브메시만** 다시 그림. 얼굴·머리카락 같은 나머지 서브메시가 스텐실을 찍지 못해, 그 뒤에 있는 몸이 '가려졌다'고 판단돼 칠해짐
- 수정: 서브메시가 2개 이상인 렌더러는 같은 메시·뼈를 쓰는 보조 SkinnedMeshRenderer(또는 MeshRenderer) 2개(`XRay Mark Proxy`, `XRay Silhouette Proxy`)를 자식으로 만들어 모든 서브메시에 같은 머티리얼을 씀. 보조 렌더러는 Ignore Raycast 레이어, 그림자 끔. 서브메시가 1개인 렌더러(Lowpoly 모델)는 기존 방식 유지
- 확인: 평소에는 몸에 하늘색이 없고, 상자 뒤로 보냈을 때 가려진 다리만 실루엣으로 보임. 콘솔 깨끗
- 남은 점: 보조 렌더러의 블렌드셰이프(표정)는 생성 시점 값으로 고정. 표정이 크게 바뀌면 얼굴 가장자리 판정이 조금 어긋날 수 있음

### 조사: 공식 MMD 모델(유키) 사용 여부
- 사용자가 받은 `Yuki.zip`은 이터널 리턴 공식 MMD 배포 페이지(event.playeternalreturn.com, 로그인 후 무료)의 모델. 압축 안에는 PMX 1개와 텍스처 4장만 있고 별도 규약 파일 없음
- 배포 페이지: "에셋 다운로드 및 활용에 대해 님블뉴런 IP 이용 정책을 준수하는 것에 동의"로 간주. 이벤트 정책에는 공식 콘텐츠로 오인될 수 있는 내용 금지, 버추얼 유튜버 사용 금지 등이 있음
- IP 이용 정책(2026.10.22): 게임 프로토타입은 허용 플랫폼 목록에 없어 사전 문의 대상, ICP 승인 게임도 공식 리소스 직접 사용 불가
- 기술적으로는 PMX → Unity 변환이 가능하지만(MMD4Mecanim, Blender mmd_tools → FBX), 이 프로젝트는 이터널 리턴 UI를 참고하고 있어 실제 실험체 모델까지 넣으면 공식 콘텐츠로 오인될 소지가 큼. 프로젝트에는 넣지 않기로 하고, 오리지널·무료 모델을 쓰는 방향 유지
