# Top-down-Survival-Prototype

이터널 리턴 같은 탑다운 서바이벌 게임의 기본 시스템을 직접 구현해 보는 프로토타입입니다. 우클릭 이동, 상호작용, 상자와 인벤토리, 쿼터뷰 카메라까지 만들었고, 전투는 아직 구현하지 않았습니다.

| 항목 | 내용 |
| --- | --- |
| 엔진 | Unity 6000.3.7f1, URP |
| 언어 | C# |
| 코드 위치 | `Assets/2. Scripts` |

## 구현한 기능

### 이동과 상호작용

- **우클릭 이동**: 마우스 위치로 레이를 쏴서 `NavMeshAgent`에 목적지를 줍니다. 우클릭을 누르고 있는 동안 계속 목적지를 갱신합니다. 바닥을 클릭하면 이동 지점 이펙트(`MoveClickEffect`: 빨간 점, 파란 링과 모이는 화살표, 보라색 육각형 격자)가 나타납니다. `S` 키로 정지합니다.
- **이동 설정 분리**: 가속도, 회전 속도, 정지 거리 같은 값은 `MovementConfig`(`ScriptableObject`)로 빼서 캐릭터 코드를 건드리지 않고 조정합니다. `NavMeshAgent`의 자동 회전은 끄고 `CharacterMovement`에서 이동 방향으로 직접 `Slerp` 회전시킵니다.
- **상호작용**: 상호작용이 가능한 오브젝트는 `IInteractable` 인터페이스를 구현합니다. 우클릭한 대상이 `IInteractable`이면 `Character.MoveAndInteract`가 대상 콜라이더의 가장 가까운 지점까지 이동시키고, 상호작용 거리 안에 들어오면 `Interact`를 호출한 뒤 멈춥니다. 상자 외에 다른 오브젝트도 인터페이스만 구현하면 같은 방식으로 붙습니다.
- **호버 강조** (`ObjectOutline`, `Custom/HighlightOutline` 셰이더): 상호작용 오브젝트는 평소 얇은 하얀 테두리, 마우스를 올리면 조금 더 두꺼운 하늘색 테두리와 옅은 칠하기가 나타나고 다른 물체에 가려져도 보입니다. 적 유닛은 호버 시 빨간색, 아군은 파란색으로 강조됩니다.

- **입력**: Unity Input System만 사용합니다(Active Input Handling = Input System Package). 키 바인딩은 `GameInput`(`Assets/2. Scripts/Input`)에 모아 두고, 다른 스크립트는 `GameInput.Move.IsPressed()`처럼 액션만 읽습니다. 플레이어 입력은 `PlayerInputHandler`가 받아 `Character`에 명령으로 넘깁니다.

- **가려짐 실루엣** (`XRaySilhouette`): 캐릭터가 오브젝트 뒤에 가려지면 가려진 부분만 반투명 실루엣으로 보입니다. 캐릭터 렌더러에 머티리얼 두 개를 덧붙여, 먼저 보이는 픽셀에 스텐실을 찍고(자기 몸에 가려진 부분 제외) 깊이 테스트가 `Greater`인 곳에만 색을 그립니다. 셰이더는 `Assets/5. Shaders/XRaySilhouette.shader`이고 Renderer Feature 설정 없이 동작합니다. 서브메시가 여러 개인 모델은 같은 메시·뼈를 쓰는 보조 렌더러로 모든 서브메시를 처리해, 자기 몸이 칠해지지 않습니다. 색은 인스펙터나 `SetColor`로 바꿀 수 있습니다.

### 카메라 (`CameraController`)

- 화면 가장자리에 마우스를 가져가면 그 방향으로 카메라가 움직이고(대각선은 정규화), 맵 범위를 벗어나지 않도록 값을 제한합니다.
- `Space`를 누르고 있으면 캐릭터를 따라가고, `Y`로 따라가기를 고정하거나 풀 수 있습니다.

### 아이템, 상자, 인벤토리

- **아이템 데이터**: `Item`을 `ScriptableObject`로 만들어 이름, 설명, 아이콘, 최대 중첩 수, 종류(소모, 장비, 재료), 등급(Mythic ~ Common 6단계)을 에셋으로 관리합니다.
- **상자**: `ChestData`에 나올 수 있는 아이템 목록과 최소·최대 칸 수를 설정하면, 상자가 생성될 때 그 범위에서 무작위로 아이템을 뽑습니다. 상자를 연 위치에서 캐릭터가 움직이면 상자 UI가 자동으로 닫히고, `Esc`로도 닫습니다.
- **인벤토리** (`PlayerInventoryManager`): 이터널 리턴처럼 칸 위치가 고정된 10칸(2x5)이고 화면 오른쪽 아래에 항상 떠 있습니다. 같은 아이템은 최대 중첩 수까지 기존 스택을 먼저 채우고, 남으면 앞쪽 빈 칸에 들어갑니다. 아이템을 빼도 다른 칸이 당겨지지 않습니다. 아이템에 마우스를 올리면 등급 색을 쓴 툴팁이 뜹니다.
- **습득과 드래그** (`ItemDragManager`): 상자 아이템을 왼클릭하면 인벤토리로 들어오고, 드래그로도 옮길 수 있습니다. 놓는 위치에 따라 결과가 달라집니다.
  - 상자에서 끌어 인벤토리 칸에 놓으면 그 칸으로 들어갑니다. 칸이 차 있으면 같은 아이템은 합치고, 아니면 빈 칸을 찾습니다.
  - 상자 안이나 다른 UI 위에 놓으면 원래 자리로 돌아갑니다.
  - UI 밖에 놓으면 캐릭터 발밑에 버려집니다. 발밑에 이미 아이템이 있으면 겹치지 않도록 바깥쪽 빈자리에 놓습니다.
  - 인벤토리끼리 끌면 자리를 바꾸고, 같은 아이템이면 합칩니다.
  - 인벤토리 아이템을 `Ctrl` + 우클릭하면 1개씩 바로 바닥에 버립니다.
  - 인벤토리가 가득 차면 경고가 뜨고 아이템은 상자에 남습니다.
- **바닥 아이템** (`DroppedItem`, `DroppedItemNameTag`): 3D 모델 없이 바닥의 아이콘과 이름표로 표시됩니다. 이름표는 오브젝트에 가려지지 않고, 마우스를 올리면 배경이 짙어지며 좌측 하단과 우측 상단에 모서리 표시가 나타납니다. 우클릭하면 다가가서 줍고, 습득 범위 안이면 `Alt` + 좌클릭으로 바로 줍습니다.

### 아이템 툴팁과 조합식

- **툴팁** (`ItemTooltipUI`): 이터널 리턴 형식으로 이름, 등급, 분류, 개수, 아이콘, 효과(초록), 최대 중첩 수량, 상위 아이템을 표시합니다. 인벤토리 아이템은 인벤토리 위 고정 위치, 상자 아이템은 마우스 커서의 왼쪽 위에 뜹니다.
- **조합식** (`ItemRecipe`, `RecipeDatabase`): 재료 A + 재료 B → 결과를 에셋으로 만들어 `Assets/3. Scriptable Objects/Recipes/RecipeDatabase`에 등록하면, 재료 툴팁의 '상위 아이템'에 자동으로 나타납니다.
- **아이템 데이터**: `Item`에 세부 분류(`category`: 음식, 음료, 재료, 무기 등)와 효과 목록(`effects`: 예) 체력 재생 / +660)이 있습니다.

### 캐릭터 머리 위 UI와 위치 표시

- **머리 위 UI** (`CharacterOverheadUI`, `OverheadUI` 프리팹): 닉네임, 레벨, HP바가 유닛을 따라다닙니다. HP바는 나 초록, 아군 파랑, 적 빨강이고 100마다 가는 눈금, 1000마다 굵은 눈금이 있습니다. 값은 각 유닛의 `UnitProfile`에서 정합니다. 씬에 아군·적 테스트 더미(체력 5000)가 있습니다.
- **장비 등급 바**: HP바 위 5칸이 왼쪽부터 무기·옷·머리·팔·신발에 장착한 아이템의 등급 색을 보여 줍니다(빈 칸은 일반 회색). 장착 데이터는 Player의 `PlayerEquipment`에 있습니다.
- **위치 표시** (`PlayerLocator`): `Space`를 누르고 있는 동안 발밑에 노란 원, 머리 위에 V자 표시가 나타납니다.

### 하단 HUD (`PlayerHUD`)

이터널 리턴의 하단 UI를 참고해 왼쪽부터 스테이터스, 장비 칸(무기·옷·머리·팔·신발), 캐릭터 초상화와 레벨, 스킬(Q W E R, 패시브, D F G)·체력바·크레딧, 인벤토리(단축키 번호 1~0) 순으로 배치했습니다. 스테이터스·스킬·장비·초상화는 아직 해당 시스템이 없어 자리만 잡은 상태이고, 체력·레벨·크레딧은 `PlayerHUD`의 `SetHealth`, `SetLevel`, `SetCredit`으로 표시만 바꿀 수 있습니다.

## 참고

- `Assets/DoubleL`(RPG Animations Pack)과 `Assets/CharacterPack Lowpoly (FREE)`는 외부 에셋입니다.
- 캐릭터 모델은 유닛의 자식 `Model`이고, `CharacterAnimator`가 이동 속도를 `CharacterLocomotion` 애니메이터(대기·걷기·달리기)에 넘깁니다. 이터널 리턴처럼 움직이는 동안 항상 달리기 동작을 쓰고(`alwaysRun`), 모델 크기로 계산한 달리기 클립의 실제 속도에 맞춰 재생 속도를 정하므로 발이 미끄러지지 않습니다. 다른 휴머노이드 모델로 바꾸려면 `Model`만 교체하면 됩니다.
- 상자 같은 오브젝트는 NavMesh에서 빠져 있어 캐릭터가 통과하지 못하고 돌아갑니다. 오브젝트를 새로 배치하면 NavMesh Surface를 다시 구워야 합니다.
