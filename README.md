# Top-down-Survival-Prototype

이터널 리턴 같은 탑다운 서바이벌 게임의 기본 시스템을 직접 구현해 보는 프로토타입입니다. 우클릭 이동, 상호작용, 상자와 인벤토리, 쿼터뷰 카메라까지 만들었고, 전투는 아직 구현하지 않았습니다.

| 항목 | 내용 |
| --- | --- |
| 엔진 | Unity 6000.3.7f1, URP |
| 언어 | C# |
| 코드 위치 | `Assets/2. Scripts` |

## 구현한 기능

### 이동과 상호작용

- **우클릭 이동**: 마우스 위치로 레이를 쏴서 `NavMeshAgent`에 목적지를 줍니다. 우클릭을 누르고 있는 동안 계속 목적지를 갱신하고, 클릭한 지점에는 이펙트를 띄웁니다. `S` 키로 정지합니다.
- **이동 설정 분리**: 가속도, 회전 속도, 정지 거리 같은 값은 `MovementConfig`(`ScriptableObject`)로 빼서 캐릭터 코드를 건드리지 않고 조정합니다. `NavMeshAgent`의 자동 회전은 끄고 `CharacterMovement`에서 이동 방향으로 직접 `Slerp` 회전시킵니다.
- **상호작용**: 상호작용이 가능한 오브젝트는 `IInteractable` 인터페이스를 구현합니다. 우클릭한 대상이 `IInteractable`이면 `Character.MoveAndInteract`가 대상 콜라이더의 가장 가까운 지점까지 이동시키고, 상호작용 거리 안에 들어오면 `Interact`를 호출한 뒤 멈춥니다. 상자 외에 다른 오브젝트도 인터페이스만 구현하면 같은 방식으로 붙습니다.
- **오브젝트 외곽선**: 마우스를 올린 오브젝트에 외곽선을 표시합니다(`ObjectOutline`). 메시를 복제해 1.1배로 키우고 앞면을 컬링해서 테두리만 보이게 했고, 외곽선 오브젝트는 `Ignore Raycast` 레이어에 두어 클릭 판정을 가리지 않게 했습니다.

### 카메라 (`CameraController`)

- 화면 가장자리에 마우스를 가져가면 그 방향으로 카메라가 움직이고(대각선은 정규화), 맵 범위를 벗어나지 않도록 값을 제한합니다.
- `Space`를 누르고 있으면 캐릭터를 따라가고, `Y`로 따라가기를 고정하거나 풀 수 있습니다.

### 아이템, 상자, 인벤토리

- **아이템 데이터**: `Item`을 `ScriptableObject`로 만들어 이름, 설명, 아이콘, 최대 중첩 수, 종류(소모, 장비, 재료), 등급(Mythic ~ Common 6단계)을 에셋으로 관리합니다.
- **상자**: `ChestData`에 나올 수 있는 아이템 목록과 최소·최대 칸 수를 설정하면, 상자가 생성될 때 그 범위에서 무작위로 아이템을 뽑습니다. 상자를 연 위치에서 캐릭터가 움직이면 상자 UI가 자동으로 닫히고, `Esc`로도 닫습니다.
- **인벤토리** (`PlayerInventory`): 슬롯을 누르면 아이템이 인벤토리로 들어옵니다. 같은 아이템은 최대 중첩 수까지 기존 스택을 먼저 채우고, 남으면 새 스택을 만듭니다. `Tab`으로 열고 닫으며, 아이템에 마우스를 올리면 등급 색을 쓴 툴팁이 뜹니다.
